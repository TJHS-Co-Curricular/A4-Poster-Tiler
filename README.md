# A4 拼贴海报（A4-Poster-Tiler）

把一张大图片**按实际尺寸**切成很多张 A4，组成一个 PDF。用一般打印机印出来，剪掉白边、粘起来，就是设定尺寸的大海报（例：51 × 43 英寸）。

## 怎么用

1. 双击 `A4-Poster-Tiler.exe`，会打开一个独立窗口（用电脑上的 Edge 或 Chrome，没有网址栏）。**关掉这个窗口 = 结束程序**（约 20 秒后）。
   想看程序的运行情况、打开 logs 文件夹或马上结束程序：按右上角「控制台」。
2. 选一张大图片：JPG、PNG，或 PDF（只用第 1 页）。
3. 填**成品尺寸**（拼好、剪好之后的大小），单位可选英寸 / 厘米。宽、高默认按图片比例锁在一起；也可以按常用尺寸 51 × 43、24 × 43、11 × 43 英寸。
4. 选纸张（A4 / A3 / Letter）和拼法（重叠粘贴 / 对边拼），填海报名称。
5. 页面马上显示要几张纸、几排几张和示意图。解析度低于 100 dpi 会用橙色提醒「印出来会糊」。
6. 按「导出 A4 拼贴 PDF」，PDF 存在 exe 旁边的 `output` 文件夹，文件名例：`颁奖典礼-A4拼贴7x4_20261126_1530.pdf`。

## 打印和拼贴

- 打印时选 **「实际大小」或「100%」**。不要选「适合页面」，也不要用 Acrobat 的「海报」。
- 纸张选 A4（或你选的纸），方向选「自动」。
- 先印第 1 张，用尺量一量（网页上写着应该是多少 mm）。不对就是打印比例没选对。
- 沿**短黑线**剪掉白边（每张上方印着要剪哪几边）。
- 重叠粘贴：从第 1 排第 1 张开始，后一张剪好的左边（或上边）对准前一张的**虚线**，压上去粘。
- 对边拼：每张剪掉四边，边对边对齐，背面用胶带贴。

## 设置（`config\config.ini`，用记事本改，改完重新打开程序）

| 设置 | 默认 | 说明 |
|---|---|---|
| `[server] access` | `local` | `lan` = 同一网络的同事也能打开 |
| `[server] port` | `5030` | 网站端口 |
| `[server] app_window` | `yes` | `yes` = 独立窗口；`no` = 用默认浏览器开分页 |
| `[server] lan_allow_edit` | `no` | 同事导出的 PDF 能不能存进这台电脑的 output |
| `[paths] output_folder` | `output` | PDF 放哪里 |
| `[tile] margin_mm` | `8` | 每张纸四周的白边（印出来边缘被切掉时改大） |
| `[tile] overlap_mm` | `10` | 重叠粘贴时相邻两张重叠多少 |

`config\config.ini` 第一次运行时自动建立。少了哪一项，程序会自动补在文件末尾，不会改你已经写的值。

## 文件夹

```
A4-Poster-Tiler.exe
config\   设置
output\   导出的 PDF
logs\     日志（出问题时把这个文件夹发给维护的人；「控制台」里有按钮可以打开）
```

## 给维护者：打包

双击 `build.bat`（需要 Go 和 Node；老师的电脑不需要）。会先跑全部测试，通过才产生 `A4-Poster-Tiler.exe`。
