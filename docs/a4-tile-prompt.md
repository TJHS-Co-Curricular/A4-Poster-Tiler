## 1. 这个程序做什么

学校要印大海报（例：51 × 43 英寸），但只有一般的 A4 打印机。程序把**一张大图片按实际尺寸切成很多张 A4**，组成一个 PDF：

- 用一般打印机按「实际大小 / 100%」印出来；
- 每张都画好剪裁线、编号和对齐虚线；
- 剪掉白边、相邻两张重叠粘起来，就是设定尺寸的海报。

使用者是学校老师和行政同事：只会双击 exe、用浏览器、照着纸上的字剪和贴。

**为什么要做**（维护者 2026-11-25）：以前用 Adobe Acrobat 的「海报」打印，51 × 43 英寸印 28 张，拼起来是 57.87 × 46.77 英寸，四周多出很多白纸，没有线，要自己量着剪。

## 2. 已经定好的规则（不要改，改要先问维护者）

| 规则 | 值 | 来源 |
|---|---|---|
| 设定的尺寸 = 拼好、剪好之后的成品尺寸 | 例：51 × 43 英寸 | 维护者定（2026-11-25） |
| 拼法 | 重叠粘贴（不是对边拼） | 维护者定（2026-11-25） |
| 每张 A4 四周白边（打印机印不到的地方） | 8 mm | 维护者定（2026-11-25） |
| 相邻两张重叠 | 10 mm | 维护者定（2026-11-25） |
| 尺寸照设定，最后一排 / 一列只印用得到的部分 | 不放大、不缩小去凑整张 | 维护者定（2026-11-25） |
| A4 直放还是横放 | 两种都算，**张数少的那个**；一样多用直放 | 维护者定（2026-11-25） |
| 程序负责切好 A4（不是交给 Acrobat 的海报模式） | — | 维护者定（2026-11-25） |

## 3. 算法（Award Ceremony 里实际在用、验证过的）

单位 mm。A4 = 210 × 297。

```js
const M = 8, O = 10;                       // 白边、重叠
function plan(Wmm, Hmm) {                   // 成品宽、高（mm）
  const one = (pw, ph) => {
    const cw = pw - 2 * M, ch = ph - 2 * M;  // 一张 A4 能印海报的区域
    const sx = cw - O, sy = ch - O;          // 每多一张，海报往前推进多少
    const cols = Wmm <= cw ? 1 : Math.ceil((Wmm - cw) / sx - 1e-6) + 1;
    const rows = Hmm <= ch ? 1 : Math.ceil((Hmm - ch) / sy - 1e-6) + 1;
    return { pw, ph, cw, ch, sx, sy, cols, rows, n: cols * rows, land: pw > ph };
  };
  const a = one(210, 297), b = one(297, 210);
  return b.n < a.n ? b : a;                 // 张数少的；一样多用直放
}
```

第 r 排、第 c 张（从 0 算）：

- 海报上的位置：`x = c × sx`，`y = r × sy`。
- 宽、高：`w = min(cw, W − x)`，`h = min(ch, H − y)`。最后一排 / 一列会比较小。
- 画到这张 A4 的 `(M, M)`，其余地方是白色。

**每张 A4 上要画的东西**（线宽约 0.25 mm）：

1. **剪裁线**：画在白边里的短黑线，不画进海报。
   - 每张都画：对准海报这一块的左边、上边。
   - 最后一列另外画右边，最后一排另外画下边，这是整张海报的外边。
   - 线从离纸边 1 mm 开始，画到离海报边 1.5 mm 为止。
2. **对齐虚线**：右边还有下一张时，画在 `x = M + sx`（重叠那 1 cm 的起点）；下面还有下一排时，画在 `y = M + sy`。
   - 黑白相间：先画白色虚线，再错开半格画黑色虚线。这样深色、浅色背景上都看得到。
   - 粘好后会被下一张盖住。
3. **上方白边的文字**：粗体「第 r 排 · 第 c 张」，后面接灰色小字：
   - 「（共 R 排 × C 张）海报名称」；
   - 再加怎么剪、怎么贴，例如「沿短黑线剪掉左边和上面的白边，对准相邻那张的虚线粘」；
   - 第一张写「第一张：沿短黑线剪掉左边和上面的白边」。

**PDF**：每页一张 A4 JPG（品质 0.92），用 DCTDecode 原样放进去，不重新压缩。页面大小用 pt：`210 / 25.4 × 72` × `297 / 25.4 × 72`，横放时对调。不用第三方库。可以直接搬 Award Ceremony 的 `public/js/control/output.js` 里的 `outPdf()`（大约 25 行）。

**完整参考代码**：Award Ceremony 仓库的 `public/js/control/poster.js`，在 `PO_A4_M` 那一段（`poA4Plan`、`poA4Export`），commit `927fac7` 之后的版本都可以。

## 4. 检查数字（写成自动化测试）

| 成品尺寸（英寸） | 结果 |
|---|---|
| 24 × 43 | 16 张，直放，4 排 × 4 张 |
| 51 × 43 | 28 张，直放，4 排 × 7 张 |
| 11 × 43 | 6 张，横放，6 排 × 1 张 |
| 8 × 10 | 2 张，直放，1 排 × 2 张（直放、横放都是 2 张，取直放） |

另外要测：

- 拼回去的总尺寸 = 设定尺寸。
- 相邻两张重叠的那 10 mm 画面完全一样。
- 最后一排 / 一列不超出海报。

## 5. 使用流程（网页）

1. 双击 exe，浏览器自动打开（只开本机 `127.0.0.1`）。
2. 选一张大图片（JPG / PNG）。
3. 填成品尺寸。
   - 单位可选英寸 / 厘米；
   - 宽、高默认按图片比例锁在一起；
   - 有常用尺寸按钮：51 × 43、24 × 43、11 × 43 英寸（Award Ceremony 的海报预设）。
4. 填海报名称（印在每张的编号旁边，也当文件名）。
5. 页面马上显示：
   - 要几张 A4、直放还是横放、几排几张；
   - 一张缩小的示意图：海报上画出每张 A4 的范围和编号，重叠的地方颜色深一点；
   - 解析度提示：图片的像素 ÷ 成品英寸 = 实际 dpi。低于 100 dpi 用橙色提示「印出来会糊」。
6. 按「导出 A4 拼贴 PDF」，存到 `output/`，文件名 `海报名称-A4拼贴7x4_20261126_1530.pdf`。
7. 页面上一直显示打印说明（大字）：
   - 打印时选「实际大小 / 100%」，不要选「适合页面」，也不要选 Acrobat 的「海报」；
   - 纸张选 A4，方向选「自动」；
   - 怎么剪、怎么贴（附一张小图）。

## 6. 技术（照全局规范）

- 项目名 `A4-Poster-Tiler`，exe 名 `A4-Poster-Tiler.exe`，中文名「A4 拼贴海报」。
- 端口：新项目从 5030 开始（见 `20-config.md` 端口表），并写进端口表。
- 切图、画线、组 PDF 都在**浏览器**里做（canvas）。服务端只负责：
  - 提供网页；
  - 把导出的 PDF 存进 `output/`；
  - 记日志。
- 文件夹：`config/config.ini`（标准 `[server]` `[paths]` `[log]`）、`output/`、`logs/`。没有名单，不需要 `Result/`、`data/`。
- 离线：网页不连任何外网资源。
- 大图片：51 × 43 英寸 @ 200 dpi ≈ 10200 × 8600 像素，浏览器 canvas 可以处理。
  - 程序**一次只建一张 A4 的 canvas**，切完就丢；
  - 原图只读一次。
